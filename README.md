## How the content pipeline fits together

```mermaid
flowchart LR
    A[Raw content] --> B[OCR correction<br/>Gemini]
    B --> C[Normalization]
    C --> D[(Vector store<br/>Pinecone)]
    D --> E[RAG layer]
    E --> F[QAC agents<br/>n8n]
    F --> G[Verified content]
```
