| [**SmartBiz Lite**](https://github.com/hades874/SmartBiz_Lite) | Bilingual business intelligence dashboard for SMEs: sales forecasting, inventory recommendations, customer segmentation, AI receipt scanning, and a loan readiness score. | Next.js, TypeScript, Genkit, Gemini, Google Sheets |

| [**Fall-Guard**](https://github.com/hades874/Fall-Guard) | Real-time fall detection from live camera feeds or video files using pose estimation, with alerts for responders. | Python, YOLOv8, OpenCV |

### Machine learning research

| Project | Findings | Stack |
| :-- | :-- | :-- |
| [**Detection to Intervention**](https://github.com/hades874/Detection-to-Intervention-Comparative-Analysis-of-Text-Classification-Models-for-Suicide-Prevention) | Compared five classifiers for detecting suicidal intent in text. Logistic Regression and SVM reached 92% accuracy with TF-IDF. | Python, scikit-learn, TF-IDF |
| [**Bengali Facebook Sentiment Analysis**](https://github.com/hades874/Sentiment-Analysis-of-Bengali-Facebook-Text-Using-Machine-Learning-and-Deep-Learning-Models) | Compared classical and deep models on a custom Bengali comment dataset. CNN performed best at about 72.7% accuracy. | Python, CNN, RNN, LSTM, GRU |
| [**Rainfall Prediction**](https://github.com/hades874/Comparative-Analysis-of-Machine-Learning-and-Deep-Learning-Models-for-Rainfall-Prediction) | Evaluated five models on Australian weather data. Random Forest had the best overall error. | Python, scikit-learn, TensorFlow, hmmlearn |
