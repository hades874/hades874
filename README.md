# Hasan Farabi

AI Product Builder / Engineer in Dhaka, Bangladesh. I build LLM-powered systems, retrieval pipelines, and the automation around them, then ship them to real users.

I work at [10 Minute School](https://10minuteschool.com) as Executive, Content Engineering.

## What I do

- **RAG and knowledge systems.** I own the TenTen Knowledgebase, a Pinecone-backed retrieval pipeline that cut manual operations effort for the content team.
- **Multi-agent automation.** Content pipelines built on n8n and Gemini, including Bangla OCR correction and QAC agents that verify and normalize academic content.
- **Full stack products.** Next.js, Node.js, Firebase, and the internal tools (CMS, dashboards, backend databases) that keep a large platform running.
- **Applied NLP research.** Aspect-based sentiment analysis, text classification, and summarization with transformer models.

## Selected work

**Insightful Analysis of Bangladeshi Airlines Reviews**
Aspect-based sentiment classification with BERT and Bengali review summarization with LLMs, built to give airlines usable service-quality signals. Thesis work, being prepared for publication.

**Detection to Intervention**
Comparative analysis of machine learning models for suicide prevention.

**SmartBiz Lite**
Independent full stack project built with Next.js, Node.js, and Firebase.

**Workflow automation**
Google Sheets and Apps Script systems for lightweight business workflows.
